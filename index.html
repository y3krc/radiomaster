Why RadioMaster + ELRS

Y3K RC runs RadioMaster because RadioMaster runs EdgeTX — open-source firmware where the radio is something you program, not a menu you're granted. Mixes compose: the Crab Fader below exists because EdgeTX will happily sum a ratcheted axis into a steering channel, a trick no menu-firmware radio can be talked into. ELRS is the same philosophy on the RF side — an open-source link where one transmitter binds the whole fleet, so the MT12 and the Pocket share a drawer of ER4-class PWM receivers that swap between trucks in minutes.

And the hardware meets the firmware halfway: inexpensive to start, upgradeable where it counts — CNC hall-effect gimbal sets drop straight in. Open firmware, open RF, hardware that invites the screwdriver. If It Moves, We Can Mod It.

Use the sounds — any RadioMaster + EdgeTX

  1. Start from an EdgeTX SD card — set one up with EdgeTX Buddy.
  2. Copy sounds/*.wav into the card's SOUNDS/en/.
  3. Assign via Special / Global Functions — they all start with z, so they cluster at the bottom of the picker.

Requirements

  • FirmwareEdgeTX
  • RadioAny RadioMaster radio
  • AudioSounds are PCM 16-bit mono 32 kHz (EdgeTX silently skips anything off-spec)
